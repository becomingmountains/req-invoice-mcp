### Does it cost anything?
The server is free and MIT licensed. Request Network credentials are free. Payers pay network gas, and Request Network may apply its own fees.

### Which networks and tokens?
Whatever Request Network supports, including Ethereum, Base, Arbitrum, Optimism, Polygon, BNB Chain and Sepolia, with USDC, USDT, DAI, ETH and more. Use `find_currency` to check.

### Is this official?
No. It's an independent community project built on Request Network's public API.

### How is this different from x402?
x402 handles instant pay-per-request payments. This handles invoices: bill now, pay later, with the payment tied to the bill. They complement each other.

### Can my assistant pay invoices automatically?
Not through this server. It returns unsigned transactions; signing happens in a wallet you control. See [For payers](/req-invoice-mcp/guides/payers/).
