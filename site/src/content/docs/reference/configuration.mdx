---
title: Configuration
description: Environment variables.
---

All settings are environment variables, set in your MCP client's config. The server stores nothing.

| Variable | Required | Description |
|---|---|---|
| `REQUEST_CLIENT_ID` | this, `REQUEST_API_KEY`, or per-route IDs | Client ID from the dashboard (route → Manage → Client IDs). |
| `REQUEST_API_KEY` | this or `REQUEST_CLIENT_ID` | Server-side API key. Takes priority over the Client ID if both are set. |
| `REQUEST_ORIGIN` | no | Only if your Client ID is restricted to a domain: an origin it allows. Not needed by default. |
| `REQUEST_DESTINATION_ID` | for `create_payment_link` | One dashboard Route ID. |
| `REQUEST_ROUTES` | to be paid in several currencies | Several Route IDs, separated by commas, each optionally followed by `=` and the Client ID generated on that route. The first is the default. See [Multiple currencies](/req-invoice-mcp/guides/payment-links/#multiple-currencies-and-networks). |
| `REQUEST_PAYEE` | for `create_invoice` with an API key | Default wallet that gets paid (`0x…` or Tron `T…`). |
| `REQUEST_NOTES_FILE` | no | Where the local notebook (names, notes, links) is saved. Default `~/.config/req-invoice-mcp/invoices.json`; `off` keeps it in memory only. |
| `REQUEST_API_URL` | no | API base URL. Default `https://api.request.network`. Must be HTTPS. |

The server checks settings at startup and exits with a clear message if something's missing or malformed.
